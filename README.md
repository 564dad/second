# second

磁悬浮小球穿环仿真实验台：四组线圈产生磁场悬浮小球，调节电流与阻尼使小球稳定穿过三个圆环并安全落回底座。

## 运行

- 直接用浏览器打开 `index.html`（无任何外部依赖）。
- 离线验证：`node test/validate.js`（与浏览器共用 `physics.js` 同一物理核心）。

## 文件

- `physics.js` — 物理核心：固定步长积分、电流一阶滞后（系统延迟）、OU 扰动、线圈热模型、安全限触发、确定性种子随机、全部工况验证。
- `index.html` — Canvas 渲染（磁场/线圈/圆环/小球/受力箭头/触发点）、Web Audio（音高随高度）、物理量读数（含最近一次变化 Δ）、暂停/单步/重置/回放、验证面板。
- `test/validate.js` — Node 验证入口。

## 已验证工况（7/7）

1. 正常工况：三段穿环并安全落座（得分 450，落速 < 1 m/s）。
2. 极限载荷：满载堵转 + 满电流 → 温度超限（120°C）触发并冻结，记录触发点位置/速度/温度/磁压。
3. 失稳工况：低阻尼 + 强扰动 → 速度超限（6 m/s）触发。
4. 同参数重复运行末态偏差 = 0（种子确定性）。
5. 暂停 + 单步与连续运行末态偏差 = 0（共用同一 step 函数）。
6. 5 次重置初始状态完全相同（固定种子，无漂移）。
7. 回放相邻记录位移有界，关键状态无跳变。
