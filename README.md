# Handmade Pool（手写台球）

纯前端台球，零第三方依赖：Canvas 2D 渲染与刚体物理全部手写，无 three.js / matter / planck，
所有画面素材（台呢布纹、库边木纹、球面高光、阴影）均为程序生成。

## 运行

```bash
npm start          # 然后浏览器打开 http://localhost:8080
# 或任意静态服务器指向本目录
```

## 物理特性

- 球为实心球（I = 2/5 m r²），球-球冲量法弹性碰撞（e=0.96），含轻微切向投掷
- 库边反弹带法向能量损耗（e=0.80），切向库边摩擦与球的角动量耦合——
  左右塞通过接触点切向速度改变第一次碰库的反射角，高低杆改变碰球/碰库后的走位
- 两段摩擦：滑动阶段动摩擦 μ=0.22，接触点滑移归零后切入纯滚动，滚动阻力使球真正停住
- 竖直轴旋转（塞）独立缓慢衰减；停稳有迟滞阈值，不会来回抖动
- 袋口按真实比例（角袋开口 ~115mm、中袋 ~130mm），带袋角（jaw）线段，
  擦袋角能掉进、远距离不会被吸

## 操作

- 移动鼠标瞄准（白球出现瞄准线与影子球），按住左键蓄力，松开出杆
- 空格同样可以蓄力/出杆；方向键微调瞄准；R 重开；D 调试面板
- 右侧面板：力度条、杆法垫（上下旋 + 左右塞，可拖动）、重开、调试开关
- 母球落袋判犯规并自动放回开球点；8 号球过早落袋会摆回顶点

## 验收自测

```bash
npm test
```

覆盖：正碰动量误差、满力 8 秒内停稳且无抖动、左右塞碰库反射角差异、
贴库球不穿模，以及 16 球满载的步进性能预算。
