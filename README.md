# 大理石大板纹理生成器

纯原生 JavaScript + Canvas 的程序化大理石纹理工具，无框架、无构建步骤、无图片素材。

## 运行

任意静态服务器指向本目录即可，例如：

```bash
python3 -m http.server 8000
# 打开 http://localhost:8000
```

## 功能

- 域扭曲（domain warping）纹路：低频 fBm 扰动场扭曲高频脉络相位
- 可调参数：随机种子、脉络密度、脉络走向、扭曲强度（连续无跳变）、色带宽度、法线强度、底色、脉色
- 同一 seed 生成 2×2 共 4 块互不相同、拼缝连续的大板
- 导出贴图三件套：底色 / 法线 / 粗糙度，单块 1024 或 2048，外加三张 2×2 图集

## 无缝原理

所有噪声都是周期噪声（晶格对周期取模），周期 = 整张 2×2 图集；脉络的线性相位项取整数系数，使正弦在图集边界闭合。四块板是同一连续场上的四个区域，因此横缝竖缝都接得上，且图集自身也能无限平铺。法线由整张图集的高度场做跨缝回绕差分得到，拼缝处法线严格连续。

脉络边缘用"到脉络中心距离 + 像素足迹下限"做解析抗锯齿，任意分辨率下放大 300% 均无锯齿、无噪点。

## 文件结构

```
index.html      页面与控件
style.css       样式
js/noise.js     带种子的周期 Perlin 噪声 / fBm
js/marble.js    纹理场生成（DOM 无关，可单测）
js/main.js      UI 交互、预览、导出
```
