# NEON ZONE — 复古街机弹珠台

纯手写的网页弹珠台：物理引擎、Canvas 渲染、WebAudio 音效全部从零实现，
**不使用任何游戏引擎、物理库或外部素材**（贴图全部程序生成，音效全部现场合成）。

## 运行

```bash
# 任意静态服务器即可（ES Module 需要 http 协议，不能 file:// 直开）
python3 -m http.server 8080
# 浏览器打开 http://localhost:8080
```

| ← / A | 左挡板 |

## 玩法

- 三条命，球掉进底部两个排水口各扣一命，三命耗尽出结算（分数 + 最高分，最高分存 localStorage）。
- 击中三个**弹力柱**（红色）得 150 分，弹力柱给固定法向冲量，绝不黏球。
- 击中**靶子**得分；同一靶子在 2.2 秒连击窗口内连续命中，得分按 1×/2×/3×… 递增。
- 点亮上方三个**琥珀色靶**（指定 multiball 组）触发第二球，两球同屏；球数回到 1 个后可再次装填。
- 两侧斜向金属导轨低弹性，把球顺势导出台面而非弹回。

## 高速不穿透是怎么保证的

1. **自适应子步进**：每帧按当前球速（含挡板尖端线速度）把时间切成若干子步，
   使每个子步的相对位移不超过 `0.6 × 球半径`，几何上不可能一步跨过任何碰撞体。
2. **扫掠连续碰撞（CCD）**：子步内对每条线段/每个圆做扫掠求根——检测运动
   胶囊末端是否重叠，重叠则二分求最早进入时刻，把球精确停在接触点再反射。
   因此 3000 px/s 的球也不会穿过挡板。
3. **挡板角速度耦合**：碰撞在挡板的运动参考系内做相对速度反射，接触点的
   表面线速度 `v = ω × r` 直接叠加给球，所以挥动中的挡板能把球明显加速打出。

## 卡死自救

用 1.2 秒**位移窗口**（而非瞬时速度）判定卡死——球在凹角里原地高速抖动也算。
两级处理：先沿自由方向/向上给冲量；两次冲量仍未脱困则传送回最近安全点，
保证球不会卡在缝里永久抖动。

## 验收

### 浏览器内（推荐，跑真实引擎）

按 `P` 打开调试面板，点「全部自测」。四项硬性指标：

- 球以 3000 px/s 打向挡板，5 次零穿透；
- 静止挡板 vs 挥动挡板的出射速度差 ≥ 30%（面板显示碰撞瞬间角速度）；
- 同一靶子连击三次，得分 1×/2×/3× 严格递增；
- 球卡凹角能自动脱困，不永久抖动。

### 无头（无浏览器环境）

本仓库环境无 JS 引擎，`tools/headless_check.py` 用 Python 按**同一套数学**
独立实现了物理镜像，跑相同用例：

```bash
python3 tools/headless_check.py
```

覆盖：穿模 ×5、挡板发力差、连击递增、卡死自救、发射导流、multiball、
完整流程计分/排水、60 秒双球长稳（无穿界/无 NaN）。

`tools/lint_js.py` 做 JS 模块的括号/字符串配平与 import/export 一致性静态检查。

## 关键参数

- 逻辑台面 720×1080，球半径 11px，重力 1500 px/s²，限速 3300 px/s
- 固定物理步长 1/120 s，最大 24 子步/固定步，单步位移上限 0.6r
- 挡板角速度 26 rad/s，弹力柱固定冲量 620 px/s
