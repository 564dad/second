# 缺齿齿轮箱 · 装配与传动仿真

一个纯前端（无构建、无外部依赖）的齿轮箱装配教学/验证仿真：玩家为缺齿传动箱选择并安装
三只齿轮，启动仿真观察啮合旋转、受力方向与合成转动声；输出轴达到目标转速即成功，
任何物理量越过硬件限值立即跳闸并定位触发点。

## 运行

```bash
# 方式一：直接用浏览器打开
open gearbox/index.html        # 或手动双击该文件

# 方式二：本地静态服务器
cd gearbox && python3 -m http.server 8080
# 浏览器访问 http://localhost:8080

# 无头验证（需要 Node 18+；无 node 时脚本会自动使用 tools/ 下的便携运行时）
bash tests/run.sh
```

## 目录结构

```

  audio.js      Web Audio 程序化合成（转动嗡鸣、噪声、松旷敲击、跳闸音）
  app.js        主控：固定步长调度、暂停/单步/重置/回放、UI 装配、页面自测
  index.html    页面结构
  style.css     样式
tests/
  verify.js       物理引擎 24 项验证（正常/极限/失稳/卡死/热保护/可重复性/重置/回放）
  dom-harness.js  最小 DOM 桩驱动的页面逻辑 16 项冒烟测试
  cdp_shot.py     仅用标准库的 CDP 客户端，用于无头浏览器截图（需配合 --remote-debugging-port）
```

> `tools/` 不入库，用于存放按需下载的便携 Node / 无头 Chromium 及其本地依赖库；
> 浏览器截图所需的中文字体安装到 `~/.fonts` 后执行 `fc-cache -f`。

## 物理模型

| 子系统 | 建模方式 |
|---|---|
| 齿轮几何 | 模数 2.5mm，节圆半径 r=zm/2；固定轴距 AB=80mm、BC=70mm，按齿数和判定健康/松旷/过紧 |
| 健康啮合 | 刚性运动学（速比 zA/zC）+ 电机 PI 闭环（抗积分饱和、扭矩斜率限制、软启动斜坡） |
| 松旷啮合 | 三自由度半隐式欧拉，1/180s 步长内再分 12 子步；两级齿侧间隙用弹簧-阻尼接触/碰撞 |
| 接触压力 | σ = 切向力 /（齿宽 × 等效接触半宽），与赫兹接触同阶标定 |
| 热模型 | 集总参数 C·dT/dt = P损耗 − H·(T−T环境)，损耗取负载功率 12% |
| 振动/失稳 | 齿面分离-再接触的相对速度冲击，取 0.25s 衰减包络；启动 0.3s 宽限窗 |
| 随机性 | 仅扭矩纹波使用 mulberry32 种子随机，**仿真步骤内不调用 Date/Math.random** |

### 硬件限值（越限即跳闸，显示触发点而非继续计算）

| 量 | 下限 | 上限 | 跳闸代码 |
|---|---|---|---|
| 输入转速 | 200 rpm | 1400 rpm | `speed`（t=0 拒绝） |
| 输出转速 | 0 | 2000 rpm | `speed` |
| 负载扭矩 | 0 | 200 N·m | `load`（t=0 拒绝） |
| 接触压力 | 0 | 800 MPa | `pressure` |
| 油温 | 0 | 120 °C | `temperature` |
| 振动速度 | 0 | 100 mm/s | `instability` |
| 轴距过紧 | — | 过盈 >1.2mm | `jam`（t=0 拒绝安装） |

## 确定性与关键交互保证

- **固定步长**：物理只由 `step()` 推进 1/180s；rAF 只按累积时间消费固定步，帧率波动不改变积分序列。
- **暂停 ≡ 单步**：两者调用同一个 `step()`，验证套件断言 N 次单步与 N 步连续运行快照逐位相同。
- **可重复性**：同参数（含种子）两次运行的全部录制快照 `JSON` 逐位一致，跳闸步号一致。
- **重置零漂移**：`reset()` 重建种子 RNG 与全部状态，连续 5 次“运行-重置”后初始快照完全相同。
- **回放无跳变**：回放读取 60Hz 录制快照而非重新积分；测试用物理最大加速度界限定级检测跳变。
- **跳闸冻结**：跳闸后 `step()` 变为空操作，状态与触发点快照保持不变。

## 四种验证工况（页面预设按钮一键载入）

| 预设 | 配置 | 预期结果（无头实测） |
|---|---|---|
| 正常工况 | 32/32/24 齿，900rpm，60N·m | 稳定，输出 ~1175rpm（目标 1200，误差 2%），无跳闸 |
| 极限载荷 | 同上，195N·m | t≈0.50s 压力跳闸（803MPa），记录位置/速度/压力/温度 |
| 失稳·松旷 | 20/28/24 齿 | 齿侧间隙导致冲击，t≈0.31s 振动包络超 100mm/s 失稳跳闸 |
| 过紧卡死 | 40/40/32 齿 | t=0 几何拒绝（过盈 10mm），无法安装 |
| 热保护（仅测试） | 32/32/24，1000rpm，140N·m | 持续满载 t≈909s 油温达 120°C 跳闸 |

## 页面读图

- 画布：三齿轮齿形与相位标记随轴旋转；啮合点颜色 = 健康（绿）/松旷（橙）/过紧（红）；
  红色箭头为切向啮合力方向与大小；右上角表盘含目标刻度与红色超速区。
- 右侧：8 项关键物理量实时值、限值范围、最近一次变化（▲▼ 与差值）；下方变化日志按时间倒序。
- 底部：6 个限值进度条（>85% 变红）+ 输出转速/压力/温度归一化趋势曲线。
- 跳闸：画布输出轴出现脉冲警示环并标注触发时刻，红色横幅给出完整触发点快照，按钮锁定直到重置。
