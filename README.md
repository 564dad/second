# second

海报批量裁切工具（纯前端，无框架、无构建步骤）。

## 运行

```bash
python3 -m http.server 8000
# 打开 http://localhost:8000
```

任何静态服务器都可以，不需要 npm install。

## 功能

- 左侧图片列表（6 张 canvas 生成的样图，1600×1000 / 1080×1080 / 1200×1600 混排）
- 裁切：拖框、8 手柄、框内移动、双击回居中；比例锁 16:9 / 4:3 / 1:1 / 3:4 / 9:16，切比例保持焦点
- 旋转：90° 步进按钮 + −15°~15° 微调滑杆；先旋转后裁切
- 调色：亮度 / 对比度 / 饱和度 / 色温 + 原图 / 胶片 / 黑白 / 高对比预设；预览与导出共用同一套像素管线（`js/pipeline.js`）
- 每张图独立状态，localStorage 持久化，刷新不丢；「全部重置」有二次确认
- 撤销：Ctrl+Z / Ctrl+Shift+Z（当前图，50 步）
- 右侧 320 / 640 / 1280 三档实时预览；确认后一键导出三档 PNG + manifest.json
- 键盘：方向键 1px、Shift+方向 10px、按住空格看原图
